# PROJ-1234 · Exclude soft-deleted add-ons from reservation totals

**Type:** Bug · **Priority:** High · **Reporter:** Support · **MR:** !701

## Description

Customers see add-ons they removed (e.g. "Extra parking") still charged in the reservation total. The add-on list on screen is correct, but the total is not.

We also need a small endpoint that returns only the add-ons total, for the new checkout summary.

## Acceptance criteria

- **AC-1** Soft-deleted add-ons never count in the reservation total.
- **AC-2** Restoring an add-on brings it back into the total.
- **AC-3** New endpoint `GET /reservations/{id}/addons/total` returns the sum of active add-ons for the caller's tenant.
- **AC-4** Totals follow the billing rounding rules.
